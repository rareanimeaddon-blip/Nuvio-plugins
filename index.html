📦 Installation

  1. Download and unzip the plugin package
  2. Host the nuvio-plugin folder (GitHub Pages, Netlify, or any static host)
  3. Copy the raw URL to manifest.json
  4. In Nuvio app: Settings → Plugins → Add and paste the URL
  5. Enable the providers you want
